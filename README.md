# HomelyHub

A full-stack property rental platform inspired by Airbnb, where users can explore properties, view property details, and manage bookings through a simple and user-friendly interface.

## Live Project

[Visit HomelyHub] https://glittering-stroopwafel-1d7c1a.netlify.app 

## Project Repository

This repository contains the source code for the HomelyHub project.

## Features

- User Registration & Login
- Browse Rental Properties
- Search Properties
- Location-based Property Search
- Property Type Filtering
- Price Filtering
- Guest-based Search
- Property Ratings
- Bedroom/Room Filtering
- Amenities Filtering
- Property Details Page
- Wishlist
- Property Booking
- Online Payment Integration
- User Profile Management
- Authentication & Authorization
- Responsive User Interface

## Tech Stack

### Frontend

- React.js
- Redux
- React Router
- Axios
- Vite
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Other Technologies

- MongoDB Atlas
- ImageKit
- Payment Gateway
- REST API
